## Task Breakdown

### 1. Test Plan Creation
- Define objectives
- Define test scope
- Identify test types (functional, non-functional)
- Define environment

### 2. Final Unit Testing
- Validate core features:
  - Authentication
  - Messaging
- Ensure no regressions after code cleanup

### 3. Bug Tracking Table
- Columns:
  - Bug ID
  - Description
  - Severity
  - Status

### 4. User Stories Review
- Update Trello stories
- Align with final functionality

### 5. Jenkins + SonarQube
- Run CI/CD pipeline
- Ensure:
  - Successful build
  - Docker deployment
  - Code quality ≥ B

### 6. Heuristic Evaluation
- Evaluate usability:
  - Navigation
  - Consistency
  - Feedback

### 7. User Acceptance Testing
- Execute real user scenarios
- Validate expected results

### 8. Documentation Updates
- Update:
  - GitHub README
  - Architecture notes
  - Trello

## Definition of Done
- Feature works as expected
- Tested (unit/UAT)
- No critical bugs
- Code quality acceptable (SonarQube ≥ B)
- Documentation updated

## Risks & Mitigation

- Time constraints → prioritize mandatory tasks
- Low code quality → fix critical issues only
- Missing tests → add minimal essential tests
